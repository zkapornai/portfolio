Overview

This project documents the full process of recreating my everyday charger purely from paper materials. Starting from measuring the original object (Fig.1–2), I explored how different paper types behave (Fig.3) and built the internal structure using layered stocks (Fig.4–9). I used the laser cutter to create the logo and the charging-part details (Fig.10–14), then assembled and refined the final form with attention to curves and fitting (Fig.15–18). The final model (Fig.19–20) aims to stay as close as possible to the real dimensions and geometry.

Reflection

I had never built a paper-based model before, so understanding how each material behaves was a real learning curve. Especially the rounded parts, which simply don’t act like the real charger’s geometry. The internal stick-structure was the hardest part, but it also taught me the most about precision, layering, and maintaining stability. Using the laser cutter for both the logo and the charging section pushed me to think about how different fabrication techniques support the final quality. Most importantly, I finally felt the difference between imagining an object and actually constructing it: measuring, adjusting, fixing, failing, and retrying. It was stressful, but I’m genuinely proud of how close the model came to the real artifact and how much I improved my hands-on skills through the process, especially if I compare it with the first tryings.
