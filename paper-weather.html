Paper Weather

A visual interface that gives changing weather data a softer, more human feel.

  • UI design
  • Data visualisation
  • Front-end

Paper Weather looks for a more tactile visual language for everyday forecasts. It pairs the clarity of a useful interface with the warmth and variation of something made by hand.

Weather is always changing, so the visual system is designed to communicate information without making every moment feel like an alert. Colour, scale and careful hierarchy help patterns emerge at a glance.

The result is a calmer way to read the conditions around us: useful data presented with enough softness to make checking the weather feel less like consulting a dashboard.
